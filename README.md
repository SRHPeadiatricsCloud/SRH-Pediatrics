# SRH-Pediatrics

Realtime Sync and Cloud Engine for the SRH Pediatrics web application.

## Deployment
- Vercel + Supabase deployment guide: `DEPLOYMENT-SUPABASE-VERCEL.md`
- First-time database bootstrap SQL: `supabase/schema.sql`

## Bilirubin calculator
The app includes **SRH Bilirubin Nomograms (MRD/090, MRD/091, ≥35 wk PT & ET)** under:
- **Calculators → Neonatal / NICU**

A standalone public static fallback is also included at:
- `docs/index.html`
